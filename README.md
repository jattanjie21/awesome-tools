## 🤝 How to Contribute

Found a tool that changed your workflow? Want to add to this list?

1. Fork this repo
2. Add your tool to the appropriate section
3. Follow the format: `**Name** | [link](url) | Description`
4. Submit a pull request with a brief description of why you're adding it

### Contribution Guidelines

- Tools should be actively maintained
- Include a direct link to the tool
- Write a clear, one-line description
- Open source tools go in "Open Source Software"
- AI/ML tools go in "AI Tools"
