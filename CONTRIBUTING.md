# Contributing Guidelines

Thanks for wanting to contribute to this awesome list! 🙌

## Before You Add

Please make sure:
1. **The tool is real & active** - It should be actively maintained or widely used
2. **It solves a real problem** - No spam or promotional fluff
3. **You've tested it** - Personal experience is valuable
4. **It's in the right category** - Open source goes in "Open Source Software", AI tools in "AI Tools"

## How to Add a Tool

### Format for Open Source Software
```markdown
| **Tool Name** | [link](https://example.com) | Brief one-line description of what it does. |
```

### Format for AI Tools
```markdown
| **Tool Name** | [link](https://example.com) | Brief one-line description of what it does. |
```

### Example PR
1. Fork the repo
2. Edit `README.md` in the appropriate section
3. Add your tool following the format above
4. Commit: `git commit -m "Add: YourToolName - brief reason"`
5. Push and create a pull request

### PR Description Template
```
## Added
- Tool name & link

## Why
Brief explanation of why this tool is useful and deserves to be in this list.

## Tested
Yes/No - Have you personally used this tool?
```

## Reporting Issues

Found a broken link or outdated tool? Open an issue with:
- Tool name
- What's wrong (broken link, inactive, etc.)
- Suggested fix (if you have one)

## Quality Standards

- **No affiliate links or sponsored content**
- **Keep descriptions short** (1-2 sentences max)
- **Tools should be free or have a generous free tier**
- **Open source tools should have clear documentation**
